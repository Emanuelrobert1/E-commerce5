# Boutique E-commerce Pro

Projet complet de boutique en ligne, organisé pour être facilement copié vers GitHub.

## Structure
- Frontend statique: HTML/CSS/JavaScript
- Données de démonstration: JSON
- Backend Python: Flask
- Backend PHP: API simple
- Administration: interface de démonstration

## Important
GitHub Pages peut héberger le frontend HTML/CSS/JS, mais n'exécute pas Python ni PHP.
Pour utiliser le backend, déployez-le sur un hébergement compatible.

## Premier démarrage frontend
Ouvrir `index.html` dans un navigateur ou publier le dépôt avec GitHub Pages.

## Backend Python
```bash
cd backend-python
pip install -r requirements.txt
python app.py
```

API: `http://127.0.0.1:5000/api/products`

## Backend PHP
Placez `backend-php` sur un serveur PHP.
